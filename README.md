# Robots at RUC

This repository contains information and example codes to work with the robotic arms at Roskilde University.

See the subfolders for detailed information.


# Grasshopper

Programs for both robots can be generated through [Grasshopper](https://discourse.mcneel.com/c/grasshopper/2) in [Rhino](https://www.rhino3d.com/).

The Grasshopper plug-in [KUKA|prc](https://prc.robotsinarchitecture.org/) can be used to simulate and generate the correct code for each robot.
